# 🚀 Career Hub AI & Auto-Apply Bot

Мульти-платформенный агрегатор IT-вакансий, интеллектуальный скоринг на базе Groq LLM, автоматический генератор персонализированных сопроводительных писем и система автооткликов на HeadHunter со встроенным веб-интерфейсом (Telegram Mini App).

---

## 🌟 Ключевые возможности

1. **Мульти-платформенный сбор вакансий:**
   - **HeadHunter (hh.ru):** парсинг выдачи по точным запросам и категориям (noExperience, remote, fullDay).
   - **Хабр Карьера:** RSS-ленты по стекам Java, Python, Backend, AI.
   - **SuperJob:** сбор Junior/Trainee позиций через открытый API.
   - **Работа.ру (Rabota.ru):** поиск по API мобильного клиента.
   - **LinkedIn:** поиск по Guest API с автоматическим обходом 429 rate limit.
   - **СЕТИ (vseti.app), Remotive:** международные и удалённые вакансии.
   - **Telegram-каналы:** мониторинг IT-каналов с джуниорскими вакансиями.

2. **Интеллектуальная фильтрация и AI-скоринг:**
   - **Строгий пре-фильтр:** мгновенно отсекает нецелевые профессии (QA, дизайн, саппорт, 1С, PHP, Middle+/Senior, недобросовестные конторы из черного списка).
   - **Groq LLM Scoring (Qwen 2.5 / LLaMA 3.3):** глубокий анализ соответствия кандидата стеку вакансии (оценка 1–10, извлечение роли, вердикт).
   - **Защита от сжигания вакансий:** безопасный TTL для истории просмотренных вакансий, защита от пропуска при лимитах API.

3. **Автоотклики и генерация сопроводительных писем:**
   - **Индивидуальные сопроводительные письма:** генерация зрелых, технических писем с привязкой к стеку (Java 21 / Spring Boot, Python FastAPI, Xray VPN Infrastructure, Fullstack JS) и ссылками на живой деплой и GitHub.
   - **HeadHunter Web Session Auto-Apply:** прямая подача отклика через веб-сессию соискателя (`hhtoken`, `_xsrf`).
   - **Обнаружение проверочных форм / тестов работодателя:** вакансии с нестандартными опросниками отправляются в Telegram с прямой кнопкой на прохождение.
   - **Автоматическое удаление отказов:** отслеживание статусов откликов и фоновая очистка отказов (`DISCARD`) из профиля HH.

4. **Веб-интерфейс и Telegram Mini App (Career Hub):**
   - Управление вакансиями по канбан-статусам: *Новые (Inbox)*, *В планах (Saved)*, *Отклики (Applied)*, *Интервью (Calls)*, *Архив*.
   - Копирование сопроводительного письма в 1 клик.
   - **Управление сессией и автооткликом:** прямо в интерфейсе можно вставить cookie с `hh.ru`, нажать «Проверить куки» и включить/выключить фоновый автоотклик.

## 🛠️ Архитектура и стек

- **Бэкенд:** Python 3.12 (многопоточный демон: фоновый монитор, Telegram bot polling, REST API сервер).
- **Фронтенд:** Tailwind CSS, Lucide Icons, Telegram WebApp SDK, SPA без внешних тяжелых фреймворков.
- **Нейросети:** Groq Cloud API (Llama 3.3 70B, Qwen 2.5 32B, Llama 3.1 8B).
- **Развёртывание:** Docker, Docker Compose, Nginx Reverse Proxy с SSL.

## 📦 Быстрый старт (Docker Compose)

### 1. Клонирование репозитория
```bash
git clone git@github.com:nikitos7626/career-hub-bot.git
cd career-hub-bot
```

### 2. Подготовка конфигурации
Скопируйте пример конфигурации:
```bash
mkdir -p data
cp bot_config.example.json data/bot_config.json
```
Отредактируйте `data/bot_config.json`:
- `bot_token`: токен вашего бота от `@BotFather`.
- `chat_id`: ваш Telegram user ID.
- `allowed_telegram_id`: ваш Telegram user ID (для авторизации в веб-интерфейсе).
- `groq_api_key`: API-ключ от console.groq.com.

### 3. Запуск сервиса
```bash
docker compose up -d --build
```

Сервис запустится и будет доступен:
- Бот в Telegram: отправка уведомлений о топовых вакансиях.
- Веб-интерфейс: `http://localhost:8088/` (или через ваш домен/Cloudflare туннель).

## 🍪 Настройка куки HeadHunter через интерфейс

1. Откройте веб-приложение Career Hub (`https://your-domain.com/` или внутри Telegram Mini App).
2. В правом верхнем углу нажмите кнопку **«Настройки»** (иконка шестерёнки).
3. В блоке **«Куки HeadHunter»**:
   - Откройте `hh.ru` в браузере с авторизованным профилем соискателя.
   - Нажмите `F12` → вкладка **Network (Сеть)** → обновите страницу (`F5`).
   - Кликните на первый запрос к `hh.ru` → найдите заголовок **Cookie** и скопируйте его значение.
   - Вставьте в поле ввода в Career Hub и нажмите **«Проверить куки»**.
4. После успешной проверки нажмите **«Сохранить»**. Бот готов автоматически отправлять отклики!

## 🔒 Безопасность

- Файлы персональных сессий, куки и история откликов хранятся исключительно в смонтированной директории `data/`, которая включена в `.gitignore`.
- Веб-интерфейс защищён сквозной аутентификацией через Telegram WebApp и одноразовые токены сессий.
